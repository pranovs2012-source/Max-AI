User: Write a function to check if a number is prime
Max: Here's a simple version:
```python
def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:
        if n % i == 0:
            return False
        i += 1
    return True
```
It only checks divisors up to the square root of n, which keeps it fast.

User: How do I find the factorial of a number?
Max: Recursively:
```python
def factorial(n):
    return 1 if n <= 1 else n * factorial(n - 1)
```
Or use the standard library: `math.factorial(5)` returns 120.

User: Write a Fibonacci function
Max: An iterative version is fast and simple:
```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print([fibonacci(i) for i in range(10)])
```

User: What is a class in Python?

User: How do I sort a list?
Max: `sorted()` returns a new list, `.sort()` sorts in place:

To sort by a key: `sorted(users, key=lambda u: u["age"])`.

User: What is a generator?
Max: A function that yields values one at a time instead of building a whole list:
```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for x in countdown(3):
    print(x)
```
It saves memory for big or endless sequences.

User: What is a decorator?

```python
    def wrapper(*args):

    return wrapper

    return f"hi {name}"

print(greet("max"))  # HI MAX
```

User: What does if __name__ == "__main__" mean?
Max: It runs the code below it only when the file is run directly, not when it's imported as a module. It keeps test or startup code from running on import.
===
User: What is the difference between == and is?
Max: `==` checks if two values are equal. `is` checks if they are the same object in memory. Use `is` only for `None`, like `if x is None:`.
===
User: Why do I get IndentationError?
Max: Python uses indentation to group code. Use 4 spaces for each level, never mix tabs and spaces, and indent every line inside an if, for, def or class block the same amount.
===
User: What is a NameError?
Max: A NameError means you used a variable or function name Python doesn't know. Check for typos, and make sure it's defined before the line that uses it.
===
User: What is a TypeError?
Max: A TypeError means an operation got the wrong type, like `"age: " + 5`. Convert first: `"age: " + str(5)`, or use an f-string: `f"age: {5}"`.
===
User: What is a KeyError?
Max: A KeyError means you asked a dictionary for a key it doesn't have. Use `d.get("key")` to get `None` instead, or check with `if "key" in d:` first.
===
User: What is an IndexError?
Max: An IndexError means you used a list index that doesn't exist, like `items[5]` on a list with 3 items. Remember indexes start at 0, so the last one is `len(items) - 1`.

User: How do I check if a string is a palindrome?
Max: ```python
def is_palindrome(s):
    s = "".join(c.lower() for c in s if c.isalnum())
    return s == s[::-1]

```

Max: First measure where the time goes with `python -m cProfile script.py`. Common fixes: use sets or dicts for lookups instead of lists, avoid repeated work inside loops, and use built-ins like sum and sorted.
