===
User: How do I fix a KeyError?
Max: A KeyError means the dictionary doesn't have that key. Fix it by checking first or using get:
```python
age = user.get("age", 0)   # 0 if "age" is missing
if "age" in user:
    print(user["age"])
```
Also print `user.keys()` to see which keys really exist.
===
User: How do I fix an IndexError?
Max: Make sure the index is inside the list. Valid indexes go from 0 to `len(items) - 1`:
```python
if i < len(items):
    print(items[i])
```
Loop with `for item in items:` instead of indexes when you can.
===
User: How do I fix a TypeError?
Max: Read which types the message mentions and convert one of them. For example, `"Total: " + 5` fails; use `"Total: " + str(5)` or `f"Total: {5}"`.
===
User: How do I fix ModuleNotFoundError?
Max: The package isn't installed in the Python you're running. Install it with `pip install package-name`, and make sure your virtual environment is activated.
===
User: How do I fix a ZeroDivisionError?
Max: Check the divisor before dividing:
```python
result = a / b if b != 0 else 0
```
===
User: Why is my loop infinite?
Max: The loop condition never becomes false. In a while loop, make sure something inside the loop changes the variable you're checking, like `i += 1`.
===
User: What is a closure in JavaScript?
Max: A closure is a function that remembers variables from where it was created, even after that outer function finished:
```javascript
function counter() {
  let count = 0;
  return () => ++count;
}
const next = counter();
next(); // 1
next(); // 2
```
===
User: What is a closure in Python?
Max: An inner function that remembers variables from its enclosing function:
```python
def multiplier(n):
    def times(x):
        return x * n
    return times

double = multiplier(2)
print(double(5))  # 10
```

Max: Use reverse, which changes the array, or toReversed for a copy:

User: How do I make a to-do list in JavaScript?
Max: ```html
<input id="task"><button id="add">Add</button>
<ul id="list"></ul>
<script>
  document.getElementById("add").addEventListener("click", () => {
    const input = document.getElementById("task");
    if (!input.value.trim()) return;
    const li = document.createElement("li");
    li.textContent = input.value;
    li.addEventListener("click", () => li.remove());
    document.getElementById("list").appendChild(li);
    input.value = "";
  });
</script>
```
Click a task to remove it.

User: Explain recursion
Max: Recursion is when a function solves a problem by calling itself on a smaller piece of it, until it reaches a simple base case.
User: Show me an example
Max: ```python
def sum_to(n):
    if n == 0:          # base case
        return 0
    return n + sum_to(n - 1)

print(sum_to(4))  # 10
```
